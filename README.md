# ハンズオン プロンプト集

第4回 AI勉強会「AIでつくる簡易BIダッシュボード」ハンズオンの配布用プロンプト集です。

**公開ページ**: https://ryochinbo.github.io/0728handson-prompts/

## 内容

無料のAIチャット(ChatGPT / Gemini / M365 Copilot)との対話だけで、CSVを読み込むBIダッシュボードをHTMLで作るための、コピペ用プロンプト集です。

| ページ | 内容 |
| --- | --- |
| 01 | 使い方・3ステップの概要 |
| 02〜04 | データ説明文(問い合わせ / 商談 / 塗料の配合実験) |
| 05 | ステップ1:可視化の検討(壁打ち) |
| 06 | ステップ2:デザイン → 設計仕様書 |
| 07 | ステップ3:実装(新規スレッド) |
| 08 | 付録:用語集 |

各コードブロック右上の「コピー」ボタンでプロンプトをコピーし、AIチャットに貼り付けて使います。

## 構成

単一の `index.html` のみで動作します(外部依存はGoogle Fontsのみ)。ハンズオンで扱うデータはすべて仮想のダミーデータです。
